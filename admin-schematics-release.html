Terbitkan SCHEMATICS

GitHub dikelola melalui server

Pilih installer .exe. Aplikasi akan memecah berkas menjadi potongan sementara, mengunggah rilis ke GitHub, lalu memperbarui schematics-update.json. Potongan sementara dihapus setelah proses selesai.

Contoh: v_0.1.25.10.26.23.15
Batas file aplikasi ini: 200 MB. Ukuran potongan unggah 10 MB.
Satu baris akan menjadi satu poin di halaman information.html.
Format satu rincian per baris: Nama bagian | penjelasan.

Yang akan diperbarui

  • Installer pada GitHub Releases dengan tag sesuai versi.
  • Manifest schematics-update.json yang dipakai aplikasi untuk memeriksa pembaruan.
  • Rincian aplikasi dan website yang ditampilkan di information.html.

Pastikan versi lebih baru dari versi aplikasi yang telah dirilis. Setelah diterbitkan, klien akan melihat update saat memeriksa manifest.
